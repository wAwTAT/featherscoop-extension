# FeatherScoop

飞书 / Lark 文档的**附件**与**正文**导出浏览器插件（Chrome / Edge，Manifest V3）。

复用浏览器现有的登录态，无需 Cookie、Token 或命令行，适合保存知识库、访谈资料等文档中的文件与正文。

## 功能

- **扫描附件**：读取文档中的全部文件块，展示名称、大小与分类。
- **批量下载**：勾选后一键保存到本地，文件名保持原样。
- **自动分组**：名称以 `【资料】` 开头的文件归入「访谈嘉宾资料」，其余归入「其他资料」。
- **增量跳过**：同名且大小一致的文件不会重复下载。
- **索引文件**：可在下载目录生成 `README.md` 附件清单。
- **正文导出**：将文档正文导出为 Markdown，并下载正文图片到 `_images/`。
- **只读分享文档可用**：优先读取页面自身的 SSR 数据，即使没有 `/space/api` 权限也能导出正文。

## 安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`），开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**仓库根目录**（包含 `manifest.json` 的目录）。
4. 打开飞书文档页面，点击工具栏中的 FeatherScoop 图标即可使用。

要求浏览器版本不低于 Chrome 111。

## 使用

### 下载附件

1. 打开需要处理的飞书文档。
2. 点击插件图标，插件会自动扫描当前页面的附件。
3. 在列表中勾选需要的文件，按需调整「保存目录」「按前缀分组」「跳过已下载」「生成索引」。
4. 点击「下载」。

默认输出结构：

```text
FeatherScoop/
├── 访谈嘉宾资料/
├── 其他资料/
├── README.md
```

### 导出正文

点击文档卡片右上角的「导出文档」，插件会：

1. 生成 `<文档标题>.md` 并保存到下载目录；
2. 将正文中的图片逐张保存到 `_images/`，扩展名按图片 MIME 类型推断；
3. 正文中的附件链接指向同目录下已下载的文件。

Markdown 与图片的路径均相对于同一个保存目录，可直接用编辑器打开查看。

## 工作原理

1. 通过 `chrome.scripting.executeScript` 在页面的 MAIN world 中读取 `window.DATA.clientVars.data`，取 `block_map` 与 `block_sequence` 还原文档结构。
2. 页面没有 SSR 数据时，回退到飞书的 `wiki/token_info` 与 `/space/api/obj/{token}/` 接口。
3. 附件与图片通过 `internal-api-drive-stream` 的预览流下载，减少「禁止下载」等限制的影响。
4. 文件写入使用 `chrome.downloads`，下载到浏览器默认下载目录下的子目录。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `scripting` | 在当前文档页读取附件与正文数据 |
| `downloads` | 保存附件、Markdown 与图片 |
| `storage` | 记忆保存目录与勾选项 |

`host_permissions` 仅包含 `*.feishu.cn`、`*.larksuite.com`、`*.larkoffice.com`。

## 已知限制

- 正文导出目前支持 `docx` 与 `wiki` 中的 `docx` 文档；表格（sheets）、多维表格（base）暂不支持。
- 富文本仅还原文本内容与基础结构，颜色、字号等样式暂不解析。
- 超大表格的文档页面首屏只携带部分内容，插件会在页面加载时自动捕获飞书分页请求的数据，导出时一并合并；若仍未补齐，会在完成后提示「部分内容未能加载」。
- 单张图片下载失败不会阻塞正文导出，可稍后重新导出。
